# PicLook

一个基于浏览器的本地媒体播放器，支持漫画、音乐和视频。无需上传文件，通过浏览器原生 API 直接读取本地文件夹，保护隐私。

## 主要功能

### 📖 漫画阅读
- 支持多种图片格式：JPG、PNG、GIF、WebP、BMP
- 支持 ZIP/CBZ 压缩包格式
- 漫画缩放、拖动浏览
- 自动保存阅读位置
- 键盘快捷键翻页（← → 或 PageUp/PageDown）

### 🎵 音乐播放
- 支持多种音频格式：MP3、M4A、WAV、OGG、FLAC
- 自动读取音频内嵌专辑封面
- **动态音频可视化波浪图**
- 跨专辑连续播放
- 完整的播放控制：播放/暂停、上一曲/下一曲

### 🎬 视频播放
- 支持多种视频格式：MP4、WebM、OGG、MOV、AVI、MKV
- 支持循环播放、自动连播
- 键盘快捷键控制：快进/快退、音量调节

## 使用方法

### 1. 直接打开（推荐）

直接在浏览器中打开 `AllinOne.html` 文件即可使用。

### 2. 分文件运行

需要同时部署以下文件：
- `index.html`
- `style.css`
- `app.js`
- `libs/jszip.min.js`
- `libs/jsmediatags.min.js`

### 3. 构建 AllinOne 版本

如果修改了源码，需要重新整合：

```bash
python build-allinone.py
```

## 快捷键

### 漫画模式
| 快捷键 | 功能 |
|--------|------|
| ← / PageUp | 上一页 |
| → / PageDown | 下一页 |
| Ctrl + ← | 上一本漫画 |
| Ctrl + → | 下一本漫画 |

### 音乐模式
| 快捷键 | 功能 |
|--------|------|
| ← | 上一曲 |
| → | 下一曲 |
| Space | 播放/暂停 |

### 视频模式
| 快捷键 | 功能 |
|--------|------|
| ← | 快退 1 秒 |
| → | 快进 1 秒 |
| ↑ | 音量 +10% |
| ↓ | 音量 -10% |
| Space | 播放/暂停 |
| Ctrl + ← | 上一个视频 |
| Ctrl + → | 下一个视频 |

## 技术特点

- **隐私安全**：所有文件仅在本地处理，不会上传到任何服务器
- **无需安装**：纯 Web 技术，直接用浏览器打开即可
- **独立部署**：一个 HTML 文件即可部署到任何静态服务器
- **现代 API**：使用 File System Access API、Audio API、Web Audio API

## 浏览器兼容性

- Chrome 86+
- Edge 86+
- 其他基于 Chromium 的浏览器

> 注意：Safari 和 Firefox 部分功能可能受限。
