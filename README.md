# PicLook
一个基于浏览器的本地媒体播放器，主要用于阅读漫画和播放音乐专辑。无需上传文件即可浏览和播放媒体内容。


## 主要功能
### 📖 漫画阅读
### 🎵 音乐播放

## 主要功能
### 📖 漫画阅读
### 🎵 音乐播放


## 目录结构
```
漫画收藏/
├── 漫画A/
│   ├── 第1话/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── 003.jpg
│   └── 第2话/
│       ├── 001.jpg
│       └── 002.jpg
└── 漫画B/
    └── 图片/
        ├── 1.png
        ├── 2.png
        └── 3.png

或者

漫画文件夹/
├── 漫画A/
│   ├── 001.jpg
│   ├── 002.jpg
│   └── 003.jpg
└── 漫画B/
    ├── 1.png
    ├── 2.png
    └── 3.png
```

```
音乐文件夹/
├── 专辑A/
│   ├── cover.jpg     （如有）
│   ├── 歌曲1.mp3
│   ├── 歌曲2.mp3
│   └── 歌曲3.mp3
└── 专辑B/
    ├── 01 - 曲目1.flac
    ├── 02 - 曲目2.flac
    └── 03 - 曲目3.flac
```
